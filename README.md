# WEOUTPUT · 微示

> 不必复杂：一个文件、一份职责、开箱即用。

**WEOUTPUT（微示）** 是一个聚焦于 **单文件工具** 的开源组织。我们希望回归工具的本质——拿来就能用，用完就放得下。

## 🎯 我们在做什么

- 📄 **单文件优先** — 每个工具只有一个文件，复制、下载、嵌入皆可
- ⚡ **开箱即用** — 零安装、零配置、零依赖，打开就能跑
- 🧩 **一份职责** — 一个文件只做一件事，做好一件事
- 🌐 **在线可试** — 无需克隆仓库，浏览器里直接体验
- 🪶 **轻量克制** — 不追求大而全，用完即走，不占用你的注意力

## 📦 工具理念

| 原则 | 说明 |
| --- | --- |
| 单文件 | 一个 `.html` / `.js` / `.py` 就是一个完整工具 |
| 零依赖 | 不引入构建链，不捆绑框架 |
| 可读性 | 源码即文档，打开就能看懂 |
| 可移植 | 复制走就能用，不绑定平台 |
| 可丢弃 | 用完即放，不制造技术债 |

> 工具应该像便利贴：需要时撕一张，用完就扔，而不是装一整套系统。

## 🧭 适合谁

- 🧑‍💻 **开发者** — 需要一个能随手改、随手嵌的小工具
- 🎓 **学习者** — 想通过短小完整的源码理解一件事怎么做
- 🛠️ **效率党** — 不想为了一个功能装一堆依赖
- 🌱 **开源新手** — 单文件是最好的第一次贡献入口

## 🤝 参与贡献

我们欢迎任何规模的贡献，尤其是「小」的贡献：

1. 🍴 Fork 仓库，新建或改进一个单文件工具
2. 🧪 确保它零依赖、可直接运行
3. 📝 在文件头部写清用途、用法与示例
4. 🚀 提交 Pull Request，说明它解决什么问题

**贡献准则：** 一个 PR 一个文件，一个文件一件事。
